# Security

Report a vulnerability through [GitHub private vulnerability reporting](https://github.com/glimpse-hq/Glimpse-Plugin/security/advisories/new). Please don't open a public issue.

This plugin only starts `glimpse mcp` from the Glimpse app. Issues in the app itself go to [glimpse-hq/Glimpse](https://github.com/glimpse-hq/Glimpse/security).
